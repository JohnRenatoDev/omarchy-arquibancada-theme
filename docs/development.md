# Artwork and development

The compositor, source artwork, installer and validation checks are maintained
in [Arquibancada tools](https://github.com/JohnRenatoDev/omarchy-arquibancada-tools). Its [build notes](https://github.com/JohnRenatoDev/omarchy-arquibancada-tools/blob/main/docs/development.md)
explain how to rebuild into a separate theme checkout.

The finished themes are in `themes/<slug>/`. The repository root is the default
Santos variant. Each club has a palette, three wallpapers and a preview.

See the [kit references](uniformes-2026.md), [stadium sources](estadios.md) and
[artwork review](mascotes-status.md) for the visual decisions.
